---

## 🎯 Visão Geral

O SisImagem é uma aplicação web Java EE para protocolo e gestão de documentos, integrando-se com banco Oracle/TRIM e repositório de arquivos.

**Tecnologias**: Java 8, Servlets/JSP, Oracle JDBC, jQuery 1.4.2, WildFly/JBoss

## ⚠️ Avisos Importantes

> [!CAUTION]
> **Vulnerabilidades de Segurança Identificadas**
> 
> O sistema atual possui vulnerabilidades críticas:
> - SQL Injection (concatenação de strings)
> - Credenciais hardcoded
> - Falta de validação de upload
> - Ausência de HTTPS obrigatório
> 
> Veja detalhes em [reverse-engineering-report.md](file:///home/bruna/sisimagem/docs/reverse-engineering-report.md#nível-5---riscos-e-recomendações)

> [!WARNING]
> **Dependências Desatualizadas**
> 
> Várias dependências estão desatualizadas e podem ter vulnerabilidades conhecidas:
> - jQuery 1.4.2 (atual: 3.x)
> - Apache Commons FileUpload 1.3.3
> - Log4j (verificar versão exata)

> [!IMPORTANT]
> **Antes de Migrar**
> 
> Complete pelo menos a **Fase 1** do [plano de ação](file:///home/bruna/sisimagem/docs/plano-acao-documentacao.md) antes de iniciar qualquer migração. Sem o schema completo do banco e regras de negócio documentadas, há alto risco de perda de funcionalidades.
